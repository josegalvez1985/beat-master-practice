# Beat Master Practice

Aplicación web (PWA) de práctica y enseñanza de batería: rudimentos, metrónomo y
lecciones guiadas. Incluye formulario de login, home y modo oscuro. Frontend en
React con TanStack Start, Tailwind CSS y componentes Radix UI.

## Desarrollo

Requisitos: Node.js y npm — [instalar con nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Scripts

| Script | Descripción |
| --- | --- |
| `npm run dev` | Servidor de desarrollo |
| `npm run build` | Build de producción |
| `npm run preview` | Previsualizar el build |
| `npm run lint` | Ejecutar ESLint |
| `npm run format` | Formatear con Prettier |
